SIDERA - The Celestial Observatory
sidera (Latin: "celestial bodies")
A digital sky observatory for Picocomputer 6502.
Sun, Moon and planets. 1900–2200, UTC. VGA required.

sidera [/config path][/date \"YYYY-MM-DD HH:MM:SS\"][/location CC|City|CC/City]

Additional options:
/view AZ,ALT       Azimuth 0..359, altitude -90..90 degrees
/fov 50..160       Horizontal FOV, multiples of 10 degrees
/grid 0..3         0: off, 1: scale, 2: crosses, 3: crosses and dots
/paths on|off      Sun/Moon paths
/planets on|off    Planet sprites
/constellations 0..4  0: off, 1: stars, 2: figures, 3: labels, 4: selected
                     4: UMa/UMi/Cru/Cen/Oct, stars and labels, no lines
                        Eight navigation stars have corner markers and names.
/live             Current UTC time; overrides saved simulation
Defaults < configuration < command line. Last repeated option wins.
/location selects a local-hour direction unless /view is also given.
Use /config to load and save complete presets.

Keys:
Arrows           Pan the view
+ / -            Adjust observation time by + / - 15 min
[ / ]            Move observation date backward / forward 1 day
Space            SIM PAUSE/PLAY; from LIVE enter PAUSE (5 min/step)
LCtrl+Left/Right  Decrease/Increase FOV by 10 deg (50–160 deg default: 120 deg)
N                Set observation time to now (computer local time)
D                Set observation date and time
L                Set location (DMS coordinates)
Ctrl+S           Save location, zone, view, FOV, G/T/C/P and LIVE/simulation time
Shift+Right      Next compass direction: N/NE/E/SE/S/SW/W/NW
Shift+Left       Previous compass direction (50 -> 45 -> 0 -> 315 deg)
G                Cycle grid and coordinate markers
T                Toggle daily Sun and Moon paths
P                Toggle planets (Mercury to Uranus)
K                Search countries and cities in a framed sky panel
Ctrl+F           Find bodies, stars or constellations by name/code/HIP
Z                Set time zone (IANA name)
C                Cycle constellation display modes
S                Solar System snapshot; Esc closes, sky and SIM pause
Ctrl+Q           Quit from any panel (either Ctrl key)

Standalone edition with embedded ROM resources.
Ctrl+S accepts either Ctrl key and saves only from the main sky view. X and plain F are unused.
Ctrl+F accepts either Ctrl key; N returns to LIVE.
FOV requires the physical left Ctrl key; right Ctrl does not change FOV.
Default settings: MSC0:/sidera.cfg. Ctrl+Q returns to the monitor.

Have fun!
